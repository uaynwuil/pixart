                     PIXART — 像素密度字符画
══════════════════════════════════════════════════════════════

  将任意图片转换为由字符构成的像素级艺术画。
  支持多种字符集、Floyd-Steinberg 抖动扩散、对比度/亮度
  调节，同时提供 CLI 命令行工具与 GUI 图形界面。

一、快速上手
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ 命令行（CLI）

      # 基本用法：宽度 80 字符，自动保持长宽比
      uv run python pixart.py photo.jpg

      # 指定宽度、方块字符集、开启抖动
      uv run python pixart.py photo.jpg -w 120 -c blocks --dither

      # 反色 + 高对比度
      uv run python pixart.py photo.jpg -w 100 -i --contrast 1.5

  ◆ 图形界面（GUI）

      直接运行：
      uv run python pixart_gui.py

      操作流程：
      1. 点击「选择图片」加载图片
      2. 在右侧面板调整参数（宽度、高度、对比度、亮度）
      3. 可选「反色」「抖动」「字符集」
      4. 实时预览字符画
      5. 点击「复制到剪贴板」一键导出

  ◆ 网页版

      在浏览器中打开 pixart.html 即可使用，无需任何后端
      服务，纯前端运行，完全离线可用。

二、核心特性
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ★ 像素密度的本质

    每个输出字符代表原始图像中一个像素块的平均亮度。
    由于终端字符的高度约为宽度的两倍，引擎在采样时将
    垂直分辨率加倍，使得圆形仍是圆形，不致变形。

  ★ 五种字符渐变集

     精细 (detailed)  —— 70 级灰度渐变，细节最丰富
     方块 (blocks)     —— █▓▒░  纯 Unicode 块，视觉粗犷
     极简 (minimal)    —— #.     两个级别，极简风格
     ASCII             —— @%#*+=-:.  经典 ASCII 艺术

  ★ Floyd-Steinberg 抖动

    开启后，引擎会将每个像素的量化误差按比例扩散到周围
    像素，使局部平均亮度得以保留。即使使用短字符渐变集
    （如 blocks 仅 5 级），也能获得丰富的灰度层次感。

  ★ 图像引擎参数

     宽度 / 高度   —— 输出字符数量（高度填 0 自动适配）
     对比度        —— 0.1× ~ 3.0× 可调
     亮度偏移      —— -128 ~ +128
     反色          —— 交换明暗映射，适合深色背景
     抖动          —— Floyd-Steinberg 误差扩散

三、完整 CLI 选项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  uv run python pixart.py [OPTIONS] <image>

  位置参数:
    image                    输入图片路径

  选项:
    -w, --width     INT      输出字符宽度（默认 80）
    --height        INT      输出字符高度（0 = 自动适配）
    -c, --char-set  TEXT     字符集：detailed | blocks |
                              minimal | ascii（默认 detailed）
    -i, --invert             反色模式
    --contrast      FLOAT    对比度倍率（默认 1.0）
    --brightness    FLOAT    亮度偏移 -128 ~ 128（默认 0）
    -d, --dither             启用 Floyd-Steinberg 抖动
    -q, --quiet              仅输出字符画，不显示统计信息
    -h, --help               显示帮助信息

  示例：
    pixart.py photo.jpg
    pixart.py photo.jpg -w 120 -c blocks
    pixart.py photo.jpg -w 60 --dither --contrast 1.5

五、技术细节
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  色深映射
  ────────────────────────────────────────────────────────
  每个输出字符从预定义的灰度渐变集中选取。引擎首先将
  输入图片缩放到 (width × height × 2) 的采样网格，
  然后对每个输出行内的垂直 strip 求平均亮度，再经过
  对比度和亮度调整，最终量化为字符索引。

  长宽比补偿（CHAR_RATIO = 2.0）
  ────────────────────────────────────────────────────────
  终端/等宽字体中，字符宽度约为高度的一半。引擎在采样
  时使用 2 倍垂直分辨率，使得字符画在终端中呈现正确的
  几何比例。

  Floyd-Steinberg 误差扩散
  ────────────────────────────────────────────────────────
  误差分配矩阵（针对已处理像素的右方与下方邻居）：

      [x+1, y]       ← 7/16
      [x-1, y+1]     ← 3/16
      [x,   y+1]     ← 5/16
      [x+1, y+1]     ← 1/16

  Rec. 601 亮度公式
  ────────────────────────────────────────────────────────
  L = 0.299 × R + 0.587 × G + 0.114 × B

  半透明像素以白色背景进行 Alpha 合成。
